# DESIGN.md — HermesUpdater 功能介绍 PPT 视觉设计

## 1. 画布与母版（A/B/C 三区，单位 px）
- 画布 1280×720，页面 padding：上 20 / 左右 60 / 下 20
- **A 标题块** 0–120：主标题 34px bold（深蓝 #0F172A），左侧 6px 宽主色竖条
- **B 内容区** 120–660（540px 可用）
- **C 页脚条** 660–720：左「HermesUpdater · 功能全景」14px #94A3B8，右页码 `NN / 19` 14px #94A3B8
- 扉页/封面/结束页用自定义版式（省略 C 区）

## 2. 颜色系统（4 hex + 中性）
| 角色 | hex | 用途 |
|---|---|---|
| 主色 | #0F172A 深蓝 | 标题文字、深色扉页底、卡片头 |
| 辅色 | #3B82F6 蓝 | 图标、流程节点、图表系列、渐变起 |
| 强调 | #F59E0B 更新橙 | 巨型数字、⚡标记、CTA、焦点数字——Supporting 页 ≤5%，Hero 页可达 15% |
| 辅助渐变端 | #06B6D4 青 | 渐变终点、次级图标 |
| 中性 | #F1F5F9 浅灰底 / #64748B 次级文字 / #94A3B8 页脚 | 背景、说明文字 |

- 背景：内容页 #FFFFFF；扉页 #0F172A 深底白字（章节切换强对比）
- 渐变方案：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)` 用于扉页装饰环、流程图节点描边、卡片图标底
- 半透明：扉页大数字 `rgba(59,130,246,0.12)` 超大衬底数字；卡片 `boxShadow: 0 4px 20px rgba(15,23,42,0.08)`

## 3. 字体系统
| 层级 | 字体 | 字号/字重 |
|---|---|---|
| 封面主标题 | 思源黑体 | 64px bold 白 |
| 章节大字/巨型数字 | 思源黑体 | 72–110px bold（数字用强调橙或渐变） |
| 页面主标题 | 思源黑体 | 34px bold #0F172A |
| 卡片小标题 | 思源黑体 | 20px bold |
| 正文 | 思源黑体 | 15–17px regular #334155，行高 1.6 |
| 脚注/页码 | 思源黑体 | 14px #94A3B8 |
- 西文/数字：Inter（与思源黑体同族混排）
- 巨型数字必须与正文不同字重字号（≥64px bold）

## 4. 配图系统
- **L1 主视觉**（SVG 结构化图形为主，风格统一：圆角矩形节点 + #3B82F6 描边 + #06B6D4 渐变连线）：
  - 04 更新流程图（左 58%）、07 网络方案矩阵（右 62%）、10 路径识别引擎图（左 60%）、11 评分环+工具清单（左 55%）、14 备份流转图（左 60%）、16 通知四层架构（右 62%）
  - 01 封面：ImageGen 生成 `cover_hero.png`（深蓝科技抽象，全幅）
- **L2**：无
- **L3 母版徽标**：页脚条左「⬡」SVG 徽标 20px，全篇位置一致
- 图标：FAIcon 统一实心风格，尺寸 28/40 两档，着色 #3B82F6 主、#F59E0B 强调

## 6. 自检要点
- 每页 1 个视觉锚点（扉页=衬底大数字/内容页=L1 SVG≥30% B区/hero=≥110px 数字）
- 相邻页版式不同；05/17 卡片版式通过图标位置与卡片头色带区分
- 强调橙只出现在：数字、⚡、关键标记、扉页编号
